# Design and Analysis of Microstrip Patch Antenna with AMC Surface

## Overview

This project presents the design and analysis of a 10 GHz X-Band Microstrip Patch Antenna integrated with a Mushroom-Type Artificial Magnetic Conductor (AMC) Surface using ANSYS HFSS.

The AMC structure improves antenna performance by:

- Gain Enhancement
- Back Radiation Reduction
- Surface Wave Suppression
- Improved Radiation Efficiency
- Better Directivity

---

## Tools Used

- Microwave Engineering Concepts

---

## Results

### Return Loss (S11)

- Without AMC: -34 dB
- With AMC: -19 dB

### Gain

- Without AMC: 5.3 dB
- With AMC: 6.0 dB

### Advantages of AMC

✔ Increased Gain

✔ Reduced Back Radiation

✔ Better Radiation Efficiency

✔ Surface Wave Suppression

✔ Improved Stealth Characteristics
